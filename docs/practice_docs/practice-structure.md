# 💻 演習コンテンツ — 全体構成

> 最終更新: 2026-03-08

## 概要

メインカリキュラム（概念解説＋シミュレーション）の**実践パート**として位置づけ。  
環境構築 → ローカルDocker操作 → 実サービス構築 → クラウドデプロイ まで段階的に進む。

## 全体構成マップ

```
Lv.0    環境構築           ← スタート
Lv.1    Docker 基礎操作
Lv.2    イメージ構築
Lv.3    Docker Compose
Lv.3.5  クラウド開発環境
Lv.4    実践プロジェクト
Lv.5    運用・デバッグ
Lv.6    CI/CD
Lv.7    クラウドデプロイ    ← 最終ゴール
```

## レベル別目次

### Lv.0 環境構築（4演習）

> **ゴール**: Docker の動作環境を自力で構築できる

| # | タイトル | 内容 | 到達確認 |
|---|---------|------|----------|
| 0-1 | 開発ツールの準備 | VS Code + 拡張機能（Docker, Dev Containers）導入 | VS Code でターミナル操作ができる |
| 0-2 | ターミナル環境の準備 | Win: Git Bash / Mac: Terminal.app + 基本コマンド | `cd`, `ls`, `pwd`, `mkdir` |
| 0-3 | Docker Desktop のインストール | Win: WSL2有効化 → Docker Desktop / Mac: Docker Desktop | `docker version` が通る |
| 0-4 | 初期動作確認 | `docker run hello-world` + Dashboard 確認 | hello-world が正常動作 |

---

### Lv.1 Docker 基礎操作（6演習）

> **ゴール**: コンテナの基本操作を一人でできる  
> メインカリキュラム Lv.1（Ch.1-6）に対応

| # | タイトル | 主要コマンド |
|---|---------|-------------|
| 1-1 | コンテナを起動してみよう | `docker run -d -p 8080:80 nginx` |
| 1-2 | コンテナの状態を確認 | `docker ps`, `docker logs` |
| 1-3 | コンテナを止めて片付けよう | `docker stop`, `docker rm`, `docker container prune` |
| 1-4 | コンテナの中に入ってみよう | `docker run -it`, `docker exec` |
| 1-5 | ポート公開とアクセス確認 | `-p` オプション、複数コンテナ |
| 1-6 | データを残そう（ボリューム） | `docker volume`, `-v`, バインドマウント |

---

### Lv.2 イメージ構築（4演習）

> **ゴール**: 独自のDockerイメージを作成し管理できる（メインカリキュラム Lv.2 対応）

| # | タイトル | 主要コマンド |
|---|---------|-------------|
| 2-1 | はじめてのDockerfile | `FROM`, `COPY`, `docker build -t` |

| 2-3 | レイヤーとキャッシュの最適化 | `docker history`, `.dockerignore` |
| 2-4 | マルチステージビルド | `COPY --from`, `AS builder` |

### Lv.3 Docker Compose（5演習）

> **ゴール**: 複数サービスを Compose で管理・連携できる（メインカリキュラム Lv.3 対応）

| # | タイトル | 対象 |
|---|---------|------|
| 3-1 | はじめての Compose | YAML基本, `docker compose up/down` |
| 3-2 | Web + DB 構成を作ろう | `depends_on`, 環境変数, サービス間通信 |
| 3-3 | 環境変数で設定を管理 | `.env`, `environment`, `env_file` |
| 3-4 | 開発環境をホットリロード | `volumes` (bind), `compose.override.yml` |
| 3-5 | 3サービス構成（総合演習） | ヘルスチェック, ログ, 依存関係管理 |

## 検討ポイント

1. **メインカリキュラムとの対応**: Lv.1-3 はメインの Ch.1-15 に直結。Lv.4以降は演習独自のステップアップ
2. **クラウド演習の課金**: 無料枠で完結する手順にするか、有料リソースは明示するか
3. **前提条件の明示**: 各レベルの前提（例: 「Lv.3 には Lv.2 完了推奨」等）
4. **Win/Mac 差異**: Lv.0 で OS 別に分岐、以降は共通
5. **演習の採点方式**: セルフチェックリスト型（現行）
